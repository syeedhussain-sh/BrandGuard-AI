## 3. Recommended Capture Specifications

- **Display Scaling:** 100% display scaling (1920×1080 resolution recommended).
- **Format:** PNG format (`.png`).
- **Theme:** Default dark glassmorphic enterprise interface.
- **Privacy:** Ensure no personal secrets, private keys, or credentials are visible in the capture.
