# BrandGuard AI — Screenshot Capture Guidelines

This directory contains the visual demonstration assets referenced in the root `README.md`.

## Required Screenshot Filenames

Please capture the following 4 actual application screens from the running website (`http://localhost:5000` or production URL) and save them with these exact filenames:

1. **`dashboard.png`**
   - **View:** Executive Brand Governance Dashboard (`/#dashboard`)
   - **Contents:** Overall brand compliance health score, risk level breakdown (Low / Med / High), recent audit activity cards, and active company banner.

2. **`content-checker.png`**
   - **View:** Marketing Content Checker (`/#checker`)
   - **Contents:** Active company selector, industry category picker, promotional marketing copy editor, character/word counters, and multi-industry preset cards (NovaTech, Tata Motors, Samsung, etc.).

3. **`audit-results.png`**
   - **View:** Governance Analysis Audit Report (`/#results`)
   - **Contents:** Issue classification breakdown, brand mismatch alert (e.g. Tata Motors selected with Nova Cloud promotional copy), category breakdown, and auto-corrected marketing copy preview.

4. **`brand-guidelines.png`**
   - **View:** Brand Governance Guidelines (`/#guidelines`)
   - **Contents:** Brand identity & tone attributes, terminology glossary, restricted phrases, claim verification rules, and the distinction between Mode A (Configured Profile) and Mode B (Universal Recommended Governance).

## Recommended Capture Specifications

- **Browser:** Chrome, Edge, or Firefox at 100% display scaling (1920x1080 resolution recommended).
- **Format:** PNG format (`.png`).
- **Theme:** Default dark glassmorphic interface with full high-contrast visibility.
